# Verification

The 0.4.1 source was tested on Windows with the supported DSH 0.2.1-rc.2 SDK. Tests distinguish simulated boundaries, optional native capture and actual host reload checks. Local activation procedures, account/session records and machine-specific receipts are deliberately not published. Full source tests need the pinned helper described in the README.

The clean publication copy passed its build, 150 source tests and four host reload checks on 25 October 2026, with zero failures. One optional native desktop capture check was skipped. Dependency audit reported zero vulnerabilities. A passing source test does not establish physical remote input or public two-device acceptance.
